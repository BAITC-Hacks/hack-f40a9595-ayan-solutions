# Новый рабочий интерфейс Graph Money

Срез: 23 сентября 2026, после перехода со Streamlit на Next.js/FastAPI по пользовательскому `GRAPH_MONEY_UI_SPEC.md`. Это отчёт об интерфейсе, не независимая оценка точности AML и не подтверждение production-security.

Последующее изменение по прямому запросу пользователя: базовая тема переведена в светлую. Белые панели, нейтральный светло-серый canvas, тёмный текст, адаптированные цвета ролей и кластеров, светлые нативные controls. Это осознанное изменение первоначального требования тёмной темы; аналитическая логика и данные не менялись.

После смены темы: production build успешен, 10 unit-тестов и все 21 Playwright-сценарий пройдены повторно (41.5 с). Светлый desktop и мобильный экран осмотрены визуально; открытая страница обновлена до новой версии.

## Реализовано

| Раздел спецификации | Реализация и проверка |
|---|---|
| AppShell | Верхняя панель, единый поиск, навигация, отдельные статусы анализа и AI, период из метаданных, служебная строка. |
| Сеть | Cytoscape, все 2248 узлов и 3119 направленных связей исходного набора, включая изоляты. Стабильные сохранённые координаты, pan/zoom, fit, fullscreen, drag только позиции. |
| Цвета и геометрия | Общий словарь шести ролей, CSS-токены, цвет по ролям/кластерам, seed-маркер, выделение объекта. Размещение сообществ не считается аналитическим признаком. |
| Фильтры | Роли OR, остальные условия AND; кластер, глубина 0–4, точный минимум приоритета, seed, boundary. Фильтры не пересчитывают признаки. |
| Окружение | 1–3 направленных перехода, отдельный временный режим с возвратом к сохранённым фильтрам. Скрытый фильтром GID остаётся доступен в поиске. |
| Таблица | Глобальный топ-50, 25/50/100 строк, неизменный глобальный rank, сортировка, локальное ограничение «Только видимые», CSV. Страница и сортировка восстанавливаются через URL/Back. |
| Общий инспектор | Точные суммы, роль/role_score/priority, условия реального правила, вклады в приоритет, ограничения, кластер; один компонент в сети и полной карточке. |
| Связи и переводы | Реальные directed edges и строки transactions, поиск контрагента, направления, суммы, пагинация. Date-only без выдуманного времени. Отдельный инспектор ребра. |
| Обзор | Общие метрики, роли, реальные компоненты отдельно от Louvain-кластеров, дневные суммы/число операций, приоритетные узлы и ограничения. |
| Кластеры | Список и детали, участники, внешние контекстные узлы, межкластерные связи, распределение ролей. Внутренняя сумма проверена по внутренним рёбрам. |
| Узлы | Все/приоритетные, фильтры, дополнительные колонки, полная карточка и окружение, копирование локальной ссылки. Неизвестный GID не заменяется случайным узлом. |
| Отчёты | Три исходных CSV без изменения схемы, manifest и ZIP с методикой и metadata выбранного run. Состояния проверок возвращает backend. |
| Данные и методика | Локальные три parquet, реальная валидация, схемы, хеши, конфигурация, правила, нормализация, ограничения, история запусков. Web-upload не нужен для этой версии и скрыт. |
| Запуски | Snapshot входов/конфигурации/выходов, разные dataset_id/run_id. Новый снимок публикуется целиком, старый доступен во время расчёта. Сохранённый run восстанавливается после рестарта без пересчёта ролей. |
| AI | Три действия, свободный уточняющий вопрос, ограниченная история, реальные GID references, run/evidence version. Запросы только по действию пользователя, backend-only ключ, валидатор и защита от инъекций сохранены. |
| Влияние на сеть, P2 | Реальное удаление одного узла из копии полного графа. Одинаковые surviving source/target множества; before/after с одинаковой геометрией. Роли и CSV не меняются. |
| Настройки | Плотность, подписи, размер узлов, reduced motion, ширина инспектора, сброс. Локально хранится только версия настроек вида. |
| Адаптивность | 1440/1920/1512/1280/1024/768/390 px: нет горизонтального скролла документа; на узких экранах инспектор в modal sheet, навигация в drawer. |
| Доступность | Skip-link, осмысленные названия icon buttons, видимый focus, клавиатурный поиск, Escape и возврат фокуса, табличная альтернатива canvas. Контраст основных токенов проверяется unit-тестами. |

## Проверено автоматически

- Python: 85 тестов, включая прежний аналитический pipeline, надёжность ввода, AI safety, FastAPI-контракты, восстановление run и симуляцию.
- Frontend: 10 unit-тестов форматов денег, ролей, фильтров/направленного окружения и контраста, включая светлую палитру и различимость всех маркеров ролей.
- Playwright: 21 сценарий, включая маршруты, поиск int64 GID, скрытый узел, реальные переводы, три CSV+ZIP, отказ AI/backend, пустой старт, быстрый выбор двух узлов, атомарный пересчёт, эксперимент, историю таблицы и responsive.
- TypeScript и production build проходят. Скриншоты создаются в игнорируемом `web/test-results/`; это визуальная проверка и проверки переполнения, не pixel-diff baseline suite.
- Все 21 браузерный сценарий повторно пройдены на production-сборке (42.7 с). Подписи мобильной легенды дополнительно проверяются на переполнение каждого элемента, а не только документа.
- Три CSV нового API побайтно совпадают с результатами прежнего CLI на исходном наборе. GID в JSON строковые, CSV сохраняет исходный int64-контракт. Денежные поля API имеют decimal-string формат; UI не суммирует округлённые отображаемые значения.

Ручная проверка production-старта с пустой папкой запусков и без ключа: показано «Данные ещё не обработаны», три файла проверены, создан первый run `716451810bb54d4f` за 1.362 с, открыты реальная сеть и три готовых выгрузки (2248/91/50 строк). Отдельные порты 3001/8001 проверены; тестовый сервер остановлен. Основной production-сервер работает на 3000/8000, сохранённые снимки восстановлены после рестарта.

На основном сервере проверены два последовательных живых обращения к AI: «Проверить гипотезу» и уточнение по названному моделью ограничению. В UI появилась история из двух реплик и ответы с привязкой к тому же run/GID. Это проверка интеграции и контекста, не оценка правильности всех ответов. Проверка browser bundle на наличие фактического ключа прошла; `npm audit --omit=dev` сообщил 0 известных уязвимостей, `pip check` не обнаружил конфликтов.

Тестовые fixtures и имитации ошибок используются только в `tests/`. Обычный UI использует завершённый реальный run; при его отсутствии показывает пустое состояние.

## Наблюдения и ограничения

- Live AI в новом UI вернул ответ, но неверно пересказал порог посредничества словами. Точная проверка `>= 0.9` отображается отдельно из backend. Структурная валидация не гарантирует смысловую точность текста; роли/рейтинги от AI не меняются.
- Без размеченных случаев нельзя заявлять accuracy или доказанную эффективность расследований. Нет аутентификации, RBAC, аудита доступа, промышленного хранения или аттестации безопасности.
- На реальном локальном запуске полный run вместе с геометрией занял около 1.5 секунды. Это единичный замер на данном компьютере, не SLA. FPS и масштаб в миллион узлов не измерялись.
- Прогресс показывает укрупнённые реальные стадии, не отдельные проценты для каждой внутренней функции; отмены backend нет, кнопка отмены не предлагается.
- Не реализованы необязательные P2: minimap, поиск путей, timeline, сохранённые аналитические справки, сравнение/удаление нескольких узлов, редактор порогов и диаграмма межкластерного уровня. Эти возможности скрыты, а не представлены заглушками.
- Дневная активность отдельного клиента, имевшаяся в резервном Streamlit, пока не перенесена как график; реальные строки переводов доступны. Полный отдельный аудит screen reader и 200% text zoom ещё не проведён; WCAG-сертификация не заявляется.
- Python testclient сообщает предупреждение об устаревающей интеграции httpx. Vitest сообщает о будущем изменении загрузчика конфигурации. Текущие тесты проходят; предупреждения не скрыты.

## Воспроизведение

Основная команда: `.venv/bin/python serve.py`. Production: `npm run build --prefix web`, затем `.venv/bin/python serve.py --production`. Старый Streamlit не удалён. Подробности установки и сценарий работы находятся в корневом README.
