# Пятиминутное демо

1. 0:00–0:30 — задача аналитика: кого проверить первым среди 2248 синтетических клиентов.
2. 0:30–1:10 — нажать «Рассчитать», показать фактическое время и верх списка.
3. 1:10–2:10 — выбрать `100000003684369100` из топа; показать признаки coordinator: девять достижимых seed, связи с другими кластерами и направленные переводы.
4. 2:10–3:00 — найти `100000008165763100` как пример distributor; затем выбрать любой gid depth=4 из CSV и объяснить границу наблюдения.
5. 3:00–3:50 — найти gid, который назовут проверяющие; показать карточку, контрагентов и направление денег.
6. 3:50–4:30 — показать дневную активность и справку аналитика. Совпадение входа и выхода в один день не означает доказанный транзит. Назвать справку правиловой, если live API не настроен/не проверен.
7. 4:30–5:00 — скачать три CSV, показать команду пересчёта, оговорить ограничения данных.

Примерные gid здесь только для репетиции; классификация их не использует. При изменении данных брать примеры из текущего результата.
