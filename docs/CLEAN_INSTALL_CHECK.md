## Выполненные команды

После клонирования и создания новой `.venv`:

```bash
.venv/bin/python -m pip install -r requirements.txt
npm ci --prefix web
.venv/bin/python -m pip check
.venv/bin/python starter.py --data data --out out
.venv/bin/python -m pytest -q
npm test --prefix web
npm run build --prefix web
```

Production-сервер запущен командой:

```bash
env -u OPENAI_API_KEY .venv/bin/python serve.py --production --port 3001 --api-port 8001
```

Из папки `web/`:

```bash
npx playwright install chromium
UI_URL=http://127.0.0.1:3001 npm run test:e2e
```

Затем production-сервер тестовой копии остановлен и проверена команда без `--production`:

```bash
env -u OPENAI_API_KEY .venv/bin/python serve.py --port 3001 --api-port 8001
```

В dev-режиме повторно пройдены браузерные сценарии полного графа и поиска GID. Команды `env -u` относятся к проверенному macOS/Unix-окружению.
